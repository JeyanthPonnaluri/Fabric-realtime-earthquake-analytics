    Gutenberg–Richter distribution

    b-value · Aki MLE

    Count of events at or above each magnitude, log scale. The fitted line uses events at or above the completeness magnitude Mc = 4.5; below it the global catalog is incomplete away from dense networks. A b-value near 1.0 is typical.

    Depth cross-section

    depth vs magnitude

    Depth increases downward. Deep events (≥300 km) occur inside subducting slabs, mainly under Fiji–Tonga, the Philippines and South America. The row at 10 km is partly the default depth assigned when depth is poorly constrained.
